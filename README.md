# Code-to-Speech Reviewer

A VS Code extension that reads your code out loud line-by-line and highlights the active line. Perfect for finding logic bugs or reviewing code hands-free.

## Features

- **Read Code:** Reads the entire file or selected text using a natural voice.
- **Line Highlighting:** Automatically highlights and scrolls to the line being read.
- **Stop Command:** Instantly stop the speech and clear highlights at any time.

## How to Use

1. Open a code file.
2. Open the **Command Palette** (`Ctrl+Shift+P`).
3. Type **"Code-to-Speech: Read My Code"** and press Enter.
4. To stop, search for **"Code-to-Speech: Stop Reading"**.

## Requirements

Requires the `say` library (installed via npm).
